# Проект "Магазин электроники"

Реализация системы управления товарами и категориями для интернет-магазина электроники.

## Реализованный функционал

### Класс Product
- **Атрибуты**: название, описание, цена, количество в наличии
- **Методы**: 
  - `__init__()` - инициализация товара
  - `__str__()` - строковое представление товара
  - `__repr__()` - представление для отладки

### Класс Category
- **Атрибуты**: название, описание, список товаров
- **Атрибуты класса**: 
  - `category_count` - счетчик количества категорий
  - `product_count` - счетчик количества товаров
- **Методы**:
  - `__init__()` - инициализация категории
  - `__str__()` - строковое представление категории
### Новая функциональность

В этой версии проекта добавлены новые возможности:

### Класс BaseProduct (абстрактный класс)
- Создан абстрактный класс `BaseProduct`, который является родительским для всех продуктов в системе.
- В нем описана общая функциональность для всех продуктов, которая включает обязательные методы и атрибуты, такие как название, описание, цена и количество товара.
  
### Классы-наследники от BaseProduct
- **Product** — основной класс для продуктов, который наследует `BaseProduct` и реализует всю общую функциональность.
  
- **Smartphone** — класс-наследник от `Product`

- **LawnGrass** — класс-наследник от `Product`

### Класс-миксин для печати информации о создании объекта
- Реализован класс-миксин, который при создании любого объекта класса `Product` (или его наследников) выводит в консоль информацию о классе объекта и его параметрах.
- Миксин добавлен в цепочку наследования, чтобы он работал вместе с основными классами.
- Созданы два класса-наследника от `Product`:
  - `Smartphone` — расширен полями:
    - `efficiency` (производительность),
    - `model` (модель),
    - `memory` (объем встроенной памяти),
    - `color` (цвет).
  - `LawnGrass` — расширен полями:
    - `country` (страна-производитель),
    - `germination_period` (срок прорастания),
    - `color` (цвет).
- Ограничение операции сложения (`__add__`):  
  Теперь складывать можно только продукты одного класса.  
  Пример: два смартфона сложить можно, смартфон и траву газонную — вызовет `TypeError`.
- Ограничение добавления продуктов в категорию:  
  В `Category.add_product()` теперь можно добавлять только объекты `Product` или его наследников (`Smartphone`, `LawnGrass`).
- Написаны тесты для новой функциональности, общее покрытие кода тестами — более 75%.

## Дополнительный функционал

- **Тестирование**: комплексное тестирование всех компонентов системы
